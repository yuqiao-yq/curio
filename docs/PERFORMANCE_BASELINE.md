# 性能基准

测量日期：2026-09-07。本轮未建立改动前的同条件基线，因此这些数值只供后续比较，不表示已提升了多少性能。

## 环境与方法

- macOS 本地开发机，Node 22.22.2、pnpm 10.33.3、Vitest 2.1.9 / jsdom。
- 命令：`pnpm bench`。每项测量窗口 1 秒，使用工具默认预热；测量时未并行运行构建、lint 或测试。
- 固定构造 100、1,000、5,000 条书签，5% 标题包含「数据库」；创建时间按 `(i * 7919) % size` 打乱，避免只测试已经排好序的输入。
- 搜索调用生产代码 `searchBookmarks` 返回全部命中；排序调用 `selectCollection(cards, 'recent')`。

## 结果

单位：毫秒 / 次。以下为本机单次基准运行的统计值。

| 书签数 | 搜索平均 | 搜索 p99 | 排序平均 | 排序 p99 |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 0.0065 | 0.0108 | 0.0054 | 0.0095 |
| 1,000 | 0.0663 | 0.0903 | 0.0923 | 0.1207 |
| 5,000 | 0.3376 | 0.4898 | 0.5394 | 0.6655 |

此结果只覆盖内存里的过滤与排序，不包括 React 渲染、存储读取、正文检索、图标、拖拽、网络或首次启动。本轮也没有测量首屏耗时、帧率、Lighthouse、堆内存或全库测试覆盖率。
