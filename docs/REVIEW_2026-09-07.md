## 已修复的发现

| 优先级 | 触发场景与影响 | 修复 |
| --- | --- | --- |
| P1 | 书签已落盘、推送定时器尚未执行时关闭页面；重启可能接收远端旧库，覆盖未同步修改，删除记录也可能重新出现 | 待同步版本、书签与页面通知同次提交；启动/在线事件续传；新编辑不会被旧请求确认掉；已看到两端冲突时停止自动覆盖 |
| P1 | 读取远端后即更新接收游标，本地备份或保存尚未成功，导致同一版本的后续通知被提前忽略 | 读取只返回候选版本；在同步锁内备份并保存后确认接收，失败时游标不前进 |
| P1 | 本机 storage.sync.set 的事件先于推送游标写入到达；清空云端也可能与另一页面的推送交错 | 偏好/书签推送、接收检查、清空共用本机同步锁；确认后过滤本机回声；清空等待进行中的推送完成 |
| P2 | 初始化分别读取分类和书签，可能跨过另一个页面的整库更新，拿到不一致组合 | 初始化从持有本地写锁的完整快照读取 |
| P2 | 检索支持书签元数据，但 RAG 开关仍要求抓取正文，阻断不发送正文的使用方式 | 有书签即可开启 RAG，正文仍需单独许可；修改入口与空状态说明 |
| P2 | 空库点击智能视图仍落到「选择分类」；虚拟网格前方标题高度未计入滚动坐标 | 允许空库智能视图展示；用 scrollMargin 换算行位置并监听前方布局变化 |

## 仍需推进的边界

- `storage.sync` 只保证当前客户端已看到的版本检查，不是跨设备事务；远端延迟到达和旧客户端并发仍可能覆盖。下一步应实现实体修订、删除标记和逐条合并。
- 持久待同步状态只覆盖书签和分类。偏好仍采用原有整份偏好同步，尚无独立的持久待同步版本。
- 所有扩展页面关闭时没有后台持续上传；下次打开新标签页会继续处理。升级前未被记录的待同步状态无法追溯恢复。
- Google Drive 保持配置入口和文档阶段；本轮没有把尚未实现的授权或上传标记可用。
- 真实浏览器权限弹窗、两设备同步、滚动帧率仍需实机验证；单元测试与构建不能替代这些验收。
