# v0.23.0 — Google Drive 同步与精简模式快速删除

## 更新内容

- 精简模式下，「+」添加框由 112px 缩小为 64px，在网格内居中显示。
- 拖动书签时，当前分类末尾的「+」变为垃圾桶；指针拖入后松手直接删除，无确认弹窗或成功提示。移开指针、取消拖动及跨分类移动保留原有行为。
- 新增可选 Google Drive 同步：首次合并预览、分类与书签逐条合并、删除同步、离线重试、后台同步及合并前本地备份。
- 提供 Cloudflare OAuth Worker、跨浏览器回调白名单和部署说明；Google 客户端密钥仅保存在 Worker Secrets。
- 改善多页面设置保存与同步协调，避免本地待保存设置被远端更新覆盖。

## 下载与升级

- Chrome / Edge / Brave / Opera：下载 `curio-0.23.0-chrome.zip`。
- Firefox：下载 `curio-0.23.0-firefox.zip`，通过调试页面临时加载；本包未经过 AMO 签名。
- `curio-0.23.0-sources.zip` 为源码包。

已使用解压目录加载扩展的用户，请将新版解压覆盖原目录，再到扩展管理页重新加载，以保持原扩展 ID 和本地数据。无需卸载旧版。

Google Drive 为可选功能，默认关闭。新用户需按 [部署说明](https://github.com/yuqiao-yq/curio/blob/v0.23.0/docs/GOOGLE_DRIVE_SETUP.md) 配置自己的授权服务与 OAuth 客户端，并把浏览器显示的完整回调地址加入白名单。已有连接继续使用本地保存的服务地址。AI 密钥、浏览记录、壁纸和本机书签关联不参与 Drive 同步。
